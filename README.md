Dolche House Salon

Full-Stack Web Development Project

About the Project

A professional website developed for Dolche House Salon in Dubai, UAE.

The website showcases salon services, pricing information, and appointment booking options.

Technologies Used

- React
- HTML5
- CSS3
- Java
- Node.js
- Database Integration

Key Features

- Beauty and hair services
- Nail care and eyelash services
- Service and pricing information
- Appointment booking options
- Business contact information
